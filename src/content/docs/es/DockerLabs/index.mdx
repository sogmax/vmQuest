## ¿Qué es DockerLabs?

**DockerLabs** es una plataforma de aprendizaje que ofrece laboratorios interactivos para practicar hacking ético utilizando contenedores Docker. Esta tecnología permite desplegar y eliminar entornos de manera automatizada y eficiente, optimizando recursos.

Cada máquina propone un flujo de aprendizaje:
- Fase de **reconocimiento** para detectar posibles vectores de intrusión.
- **Explotación** de vulnerabilidades.
- **Escalada de privilegios** para acceder como administrador.

Los objetivos clave son descubrir algunas *flags*:
- `user.txt` para el usuario con privilegios limitados.
- `root.txt` para el acceso completo.

Las máquinas están clasificadas por nivel de dificultad.
