## Introducción

Este documento presenta la resolución completa de la máquina **PressEnter**, desarrollada por *d1se0* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone un sitio WordPress en un dominio virtual. Mediante enumeración con `wpscan`, se identifican usuarios válidos y, tras un ataque de fuerza bruta, se obtienen credenciales de acceso al panel de administración. Una vez dentro, se abusa del editor de temas de WordPress para subir una webshell y obtener ejecución remota de comandos como `www-data`.
A continuación, se extraen credenciales del archivo `wp-config.php` que permiten acceder a la base de datos y recuperar credenciales del usuario `enter`. Con estas credenciales, se accede al sistema y finalmente se obtiene acceso a `root` mediante `su`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip PressEnter.zip
sudo bash auto_deploy.sh PressEnter.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p PressEnter/{content,exploits,nmap,scripts}
cd PressEnter
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1762656224/Ports_behv2f.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p80 172.17.0.2 -oN targeted
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-lowercase-2.3-medium.txt \
  -x php,html,txt,js -t 200
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1762656222/Gobuster_tzd6xn.png)

Se detecta una referencia al dominio virtual `pressenter.hl`. Se agrega al `/etc/hosts`:

```bash
echo "172.17.0.2 pressenter.hl" | sudo tee -a /etc/hosts
```

Accediendo al dominio, se carga un sitio WordPress:

![PressEnter Index](https://res.cloudinary.com/dewqswzke/image/upload/v1762656224/PressEnterIndex_bxsv2j.png)

Se enumera el sitio con `wpscan`:

```bash
wpscan --url http://pressenter.hl --enumerate u,vp
```

![Users](https://res.cloudinary.com/dewqswzke/image/upload/v1762656228/UsersWps_jbjr7o.png)

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Fuerza bruta en WordPress

Con los usuarios identificados, se realiza un ataque de fuerza bruta:

```bash
wpscan --url http://pressenter.hl -l pressi -P /usr/share/wordlists/rockyou.txt
```

![Wpscan](https://res.cloudinary.com/dewqswzke/image/upload/v1762656229/WpsBf_vhg4mp.png)

Se obtienen credenciales válidas para el panel de WordPress.

### 2.2 Subida de webshell

Se accede al panel de administración (`/wp-admin`):

![Dashboard](https://res.cloudinary.com/dewqswzke/image/upload/v1762656221/Dashboard_rlpvyp.png)

El editor de temas (Theme File Editor) está habilitado. Se modifica el archivo `index.php` del tema activo para agregar una webshell.

Se inicia un listener:

```bash
nc -nlvp 443
```

Se accede al archivo modificado:

```
http://pressenter.hl/wp-content/themes/twentytwentytwo/index.php
```

![Reverse](https://res.cloudinary.com/dewqswzke/image/upload/v1762656224/Reverse_gwb7zk.png)

## Paso 3 — Escalada de privilegios

### 3.1 De www-data → enter

Se localiza el archivo de configuración de WordPress:

```
/var/www/pressenter/wp-config.php
```

![Wp-config](https://res.cloudinary.com/dewqswzke/image/upload/v1762656228/Wp-config.php_ybscad.png)

Se extraen las credenciales de la base de datos. Se accede a MySQL:

```bash
mysql -u admin -p'rooteable' -h 127.0.0.1
```

Se inspecciona la tabla `wp_users` para recuperar credenciales adicionales:

![Usernames](https://res.cloudinary.com/dewqswzke/image/upload/v1762656227/Usernames_rdtqn8.png)

Con las credenciales obtenidas, se accede como el usuario `enter`:

```bash
su enter
```

![Enter](https://res.cloudinary.com/dewqswzke/image/upload/v1762656222/Enter_qan3ea.png)

### 3.2 De enter → root

Se cambia al usuario `root`:

```bash
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1762656225/Root_uvbdrw.png)
