## ¿Qué es VulnHub?

**VulnHub** es una plataforma que proporciona entornos controlados para practicar hacking ético, análisis de vulnerabilidades y administración de sistemas. Permite adquirir experiencia práctica en ciberseguridad mediante máquinas virtuales diseñadas para simular situaciones reales.

Cada máquina propone un recorrido técnico que suele incluir:
- Fase de **reconocimiento** para descubrir vectores de entrada.
- **Explotación** de vulnerabilidades para acceder al sistema.
- **Escalada de privilegios** para obtener control total.

El objetivo final es obtener usuario adminitrador.

Las máquinas están clasificadas por nivel de dificultad: *Very Easy*, *Easy*, *Medium*, *Hard* y *Very Hard*.
