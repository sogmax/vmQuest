## ¿Qué es HackMyVM?

HackMyVM es una plataforma que ofrece un entorno de entrenamiento y aprendizaje sobre conceptos de seguridad informática totalmente gratuito1. Esencialmente, es un entorno controlado que nos permite practicar técnicas de hacking, las mismas que se emplean en el mundo real1.

Cada máquina presenta diferentes etapas. En primer lugar, debemos llevar a cabo una fase inicial de reconocimiento, a través de la cual detectaremos posibles vías de intrusión al sistema2. Finalmente, realizamos una escalada de privilegios para obtener el máximo alcance2. Para asegurarnos de que hemos “pwned” las máquinas, la idea es descubrir las “flags”: user.txt para el usuario de bajos privilegios y root.txt para el usuario de altos privilegios2.
