Bienvenido a mi página personal. Aquí encontrarás recursos, notas y experiencias relacionadas con la **ciberseguridad**, organizadas de forma clara y accesible.

Este sitio está pensado como una bitácora personal, pero también como una guía para cualquier persona interesada en aprender y explorar este mundo.

## 🧭 ¿Qué puedes encontrar aquí?

- 📖 **Blog**: Publicaciones donde comparto ideas, aprendizajes y reflexiones sobre distintos temas relacionados con seguridad informática.
- 🧪 **CTFs**: Retos que he resuelto con explicaciones paso a paso, ideales si estás aprendiendo.
- 📝 **Notas**: Fragmentos rápidos y prácticos sobre herramientas, conceptos, comandos útiles y cheatsheets.
- 📄 **Informes Profesionales**: Algunos retos y análisis más avanzados están documentados en **formatos LaTeX**, simulando reportes reales de pentesting profesional.

## 📂 Estructura del sitio

Todo el contenido está organizado en secciones accesibles desde el menú superior. También puedes usar la barra de búsqueda para encontrar temas específicos de forma rápida.
